Not executed here.

The delivery exits USEREXIT_SAVE_DOCUMENT_PREPARE (SAPMV50A FORM BELEG_SICHERN_DET_CHECK, line 432) and USEREXIT_SAVE_DOCUMENT (FORM BELEG_SICHERN_POST, line 1577) are separate steps.
T SD.DLV.REVERSE_GI: I_SIMULATE exists in the signature; behaviour not tested.

## D. Rejected candidates
R SD.CREDIT.RELEASE: SD_ORDER_CREDIT_RELEASE has no authority check, no return table, saves with commit; the standard dialog (VKM3) checks V_VBUK_FRE / V_KNKK_FRE before calling it. A safe wrapper would need those checks plus the credit master (blocked data). Not offered.
R BAPI_SALESORDER_GETLIST: customer-centred, returns the customer name; not used for lists.
R BAPI_DELIVERYPROCESSING_EXEC: not a delivery creation for orders; not used.

H Amounts: the BAPI interface returns amounts in the internal 2-decimal scale; the handler converts with CURRENCY_AMOUNT_SAP_TO_BAPI (KRW 1,500 is held as 15.00)
